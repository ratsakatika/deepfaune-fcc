Camera-trap classification: user guide

This tool reviews the camera-trap photographs on the hard drive and records the species in each image. It then produces summary tables and an interactive dashboard. You do not need to use the command line; the steps below are all you need.

Running the tool

  1. Connect the "My Book" hard drive to the computer.
  2. Open the Run DeepFaune icon on the desktop (double-click it).
    The first time only: right-click the icon and choose Allow Launching, then open it.
  3. The tool asks you to confirm a few settings. Press Enter to accept a suggested value, or type a new value and then press Enter.
  4. Processing begins. A live display shows how many images are done, the percentage complete, and the estimated finish time.

What the settings mean

At step 3 the tool shows a few settings. You can press Enter to accept the recommended values; they are sensible for this survey. If you do want to change one, here is what each means.

  • Confidence threshold (recommended 0.5) - how sure the tool must be before it names a species. A higher value (for example 0.8) means it only commits when very confident: fewer wrong names, but more animals are left labelled "undefined". A lower value names more photos, but more of those names are wrong. 0.5 is a balanced middle.
  • Sequence gap (recommended 20 seconds) - photos taken within this many seconds at the same camera are treated as one sighting, so a quick burst of frames is counted once rather than many times. A larger gap groups more photos together; a smaller gap counts them more separately.
  • Detector (recommended DF) - the method that first finds the animal in each photo. DF is the fastest. The others are more thorough but slower.
  • Birds (recommended on) - also sorts birds into groups, such as corvid, raptor or passerine, instead of just "bird".
  • Processor cores (recommended 4) - how much of the computer to use. More is faster but makes the computer work harder; fewer is gentler.

The other settings can be left as they are.

While it is processing

  • A large archive can take several days. This is expected.
  • You may close the window or disconnect from the computer (if connected remotely); processing continues on the computer itself.
  • Open the Run DeepFaune icon again at any time to view progress.
  • Keep the hard drive connected while it runs.

Adding new photographs later

In normal use you will not reprocess the whole archive. When you copy new camera-trap photographs onto the hard drive, run the tool again. It processes only the new folders and updates the results and the dashboard. This is the main day-to-day use of the tool.

Results

When processing finishes, the dashboard opens automatically in a web browser. The following files are saved to the desktop:

  • deepfaune_dashboard.html - interactive charts and a camera map. Open it in a web browser. It also refreshes while processing, so you can open it early to follow progress.
  • deepfaune_wildlife.csv - the animal detections only. Opens in Excel.
  • deepfaune_summary.csv - totals per species and per camera. Opens in Excel.
  • deepfaune_master.csv - every image. This file is very large, so open it in R rather than Excel.

If processing stops

If the hard drive disconnects or the computer restarts, reconnect the drive and open the Run DeepFaune icon again. The tool resumes from where it stopped and never repeats work it has already completed.
