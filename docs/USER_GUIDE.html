How to use the camera photo sorter

This program looks at the camera-trap photos on the hard drive and writes down which animal is in each photo. You do not need to know anything about computers. Follow the steps below. Each step is simple.

What you need

  1. The grey computer (it can stay switched on).
  2. The black "My Book" hard drive with the photos.

Steps to start

  1. Plug the black hard drive into the computer with its cable.
  2. On the screen, find the icon called dfrun (DeepFaune) and double-click it.
    The very first time only: right-click the icon, choose Allow Launching, then double-click it.
  3. A window with text opens and asks you a few short questions. For each question you can just press the Enter key to accept the suggestion. If you want to change a number, type the new number and then press Enter.
  4. The program starts sorting the photos. You will see a screen that updates by itself, showing how many photos are done, how far along it is, and how much time is left.

While it is working

  • It is slow. There are about 1.8 million photos, so it can take several days. This is normal.
  • You can close the window or disconnect your own laptop. The grey computer keeps working on its own.
  • To look at the progress again later, just double-click the dfrun (DeepFaune) icon again. It will show the live screen.
  • Please do not unplug the hard drive while it is working.

When it finishes

  1. A colourful dashboard opens by itself in the web browser, with charts and a map of the animals found.
  2. On the screen (the Desktop) you will find these files:
    • deepfaune_dashboard.html - the charts and map. Double-click to open it.
    • deepfaune_wildlife.csv - a table of only the animal photos. Opens in Excel.
    • deepfaune_summary.csv - counts per animal and per camera. Opens in Excel.
    • deepfaune_master.csv - every photo. This one is very large, so Excel cannot open all of it; use the wildlife and summary files instead.

The dashboard also refreshes while the program runs, so you can open it early to watch the results grow.

If it stops before finishing

Sometimes the hard drive disconnects, or the computer restarts. That is fine. Just plug the drive back in and double-click the dfrun (DeepFaune) icon again. It carries on from where it stopped. It never repeats work it already did.
